# Agent Hub

Приложение для Windows, в котором ИИ-агенты с разных аккаунтов (Google/Gemini, Claude, Codex)
работают одной командой: общий чат, лидер раздаёт задачи, участники правят файлы проекта.

## Запуск

Ярлык **Agent Hub** на рабочем столе или в меню «Пуск».
Приложение установлено в `%LOCALAPPDATA%\Programs\AgentHub`.

- Данные (агенты, чаты, входы в аккаунты, скиллы): `%APPDATA%\Agent Hub\data`
- Проекты по умолчанию: `Документы\AgentHub`

Для установки программ агентов из приложения нужен Node.js (nodejs.org).

## Аккаунты

Слева внизу — **Google**, **Claude**, **Codex**. Программа агента установится сама, затем откроется вход в браузере.
У каждого агента свой профиль и своя квота. Клик по агенту открывает панель: вход/выход, модель,
лидер, специализация, инструкции, свобода действий, скиллы.

Про Antigravity: Google-аккаунты подключаются через Gemini CLI (те же модели Gemini).
Claude и GPT внутри Antigravity так не доступны — для них добавьте агентов Claude и Codex.

## Скиллы

Вкладка «Скиллы»: загрузите папку с `SKILL.md`, `.md`-файл или `.zip` (можно перетащить), либо напишите скилл.
Каждый скилл выдаётся **всем** или **выбранным** агентам; у агента их можно включать в его панели.
Скиллы копируются туда, где их ищет программа агента:
Claude → `<профиль>\skills`, Codex → `<профиль>\skills`, Gemini → `<профиль>\.gemini\skills`.

## Несколько устройств

**Пошаговая инструкция: [ВТОРОЙ-КОМПЬЮТЕР.md](ВТОРОЙ-КОМПЬЮТЕР.md).**

«Настройки» → «Устройства и синхронизация». Три способа связи:

- **Этот компьютер — главный.** Он сам раздаёт зашифрованное хранилище вашим устройствам, без облака.
  Для каждого устройства создаётся **доступ с личным паролем**; пароль не хранится, только производные ключи.
  Адрес для подключения показан в настройках (домашняя сеть; из любого места — через Tailscale).
  Сервер отдаёт только зашифрованное хранилище и только по действующему доступу: каждый запрос подписан
  ключом доступа, повтор перехваченного запроса не сработает, после 8 неверных попыток адрес блокируется
  на 30 минут, один доступ — одно устройство. Любой другой запрос (файлы, проекты, настройки) получает отказ
  и попадает в журнал с уведомлением. Отзыв доступа стирает входы на том устройстве и меняет ключ хранилища.
- **Подключиться к главному** — адрес главного компьютера, имя доступа и его пароль.
- **Облачная папка** — Google Диск, OneDrive или Яндекс Диск на всех устройствах.

На новом устройстве распакуйте установщик (кнопка «Установщик» в том же разделе), запустите `AgentHub.exe`
и подключитесь — агенты, входы в аккаунты и MCP-серверы появятся сами. Для программ агентов нужен Node.js.

- Пароль синхронизации по сети не передаётся. Ключ на диске защищён Windows (DPAPI).
- Токены и ключи MCP-серверов в интерфейсе показываются звёздочками.
- Основное API приложения доступно только окну приложения: чужие страницы в браузере к нему не обратятся.
- Хранилище — зашифрованный `vault.json` (AES-256-GCM, ключ из пароля через scrypt).
- Обновлённые входы (сервисы периодически меняют токены) расходятся по устройствам примерно раз в минуту.
- Выход из аккаунта у агента при включённой синхронизации действует на всех устройствах.
- «Выйти на этом устройстве» в списке устройств удаляет входы на выбранном устройстве, когда оно выйдет в сеть.
  Чтобы отозвать доступ сразу (например, устройство украли), выйдите на всех устройствах на сайте сервиса
  и войдите заново на главном компьютере.

## MCP — инструменты агентов

Вкладка «MCP»: готовые серверы подключаются одним нажатием (браузер Playwright, Chrome DevTools, Context7, пошаговое мышление,
память, GitHub). Можно добавить свой сервер (программа или HTTP-адрес), вставить JSON-конфиг (`{"mcpServers": {...}}`
из README сервера, Cursor или Claude Desktop) или забрать все серверы из Claude Desktop.
Каждый сервер выдаётся **всем** или **выбранным** агентам; кнопка «Проверить» запускает его и показывает инструменты.
Agent Hub сам прописывает серверы программам агентов:
Claude → `--mcp-config <профиль>\agenthub-mcp.json`, Codex → блок в `<профиль>\config.toml`, Gemini → `<профиль>\.gemini\settings.json`.

## Команда — один проект, общий мозг

- **Общая память** (вкладка «Память», файл `.agenthub/MEMORY.md` в папке проекта): цель, архитектура, план,
  решения, договорённости. Каждый агент получает её перед работой и дописывает важное после.
- **Доска задач** (вкладка «Задачи»): лидер раздаёт задачи строками
  `@Имя: что сделать [файлы: a.py, src/] [после #1]` — с закреплёнными файлами и зависимостями.
  Статусы: ожидает → в работе → на проверке → готово. Лидер принимает `[принято #N]`, завершает `[ГОТОВО]`.
- **Распределение файлов**: задачи с общими файлами выполняются по очереди, правки чужих файлов — предупреждение в чате.
- **История изменений**: каждый шаг агента сохраняется отдельно (теневой git в `.agenthub/history`, ваш git не затрагивается).
  Под сообщением агента видно, какие файлы он изменил, и есть кнопка «Откатить этот шаг».
- **«Обсудить сначала»** (переключатель у поля ввода): все участники предлагают подход без изменения файлов,
  лидер собирает единый план, записывает его в память и раздаёт задачи.
- Сообщение без `@` получает лидер. `@Имя: …` — задача конкретному агенту, `@all: …` — всем.
- Enter — отправить, Shift+Enter — новая строка. «Остановить» — прервать работу.

## Разработка

```
npm install
npm start               # запустить приложение из исходников
node build-app.js       # собрать и установить (ярлыки на рабочем столе и в «Пуске»)
node server.js          # старый режим: сервер + окно браузера
```
