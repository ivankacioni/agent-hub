Доска задач

Общий план команды. Лидер раздаёт задачи с закреплёнными файлами и зависимостями, участники берут их в работу, лидер принимает результат. Задачи с общими файлами выполняются по очереди.

Общая память проекта

Цель, архитектура, план, решения и договорённости. Каждый агент читает её перед работой и дописывает важное после — так команда работает как одно целое, даже на длинном проекте. Можно править вручную.

Скиллы

Готовые инструкции и знания, которые получают агенты: стиль кода, правила проекта, чек-листы. Формат как у Claude — папка с SKILL.md, а также отдельный .md-файл или .zip. Каждый скилл можно выдать всем агентам или выбранным.

Перетащите сюда папку скилла, SKILL.md, .md или .zip

MCP-серверы

Инструменты для агентов по протоколу MCP: браузер, документация, GitHub, базы данных и всё, что поддерживает MCP. Сервер подключается всем агентам или выбранным — Agent Hub сам прописывает его в Claude, Codex и Gemini.

Готовые серверы — нажмите, чтобы подключить

Синхронизация устройств

Этот компьютер будет хранить зашифрованные входы и раздавать их вашим устройствам — без облака. После включения создайте для каждого устройства доступ со своим паролем. Компьютер должен быть включён с открытым Agent Hub, когда другие устройства синхронизируются.
Код — из любой сети: на главном «Доступ через интернет» → «Код» у доступа. Адрес — только в одной сети с главным.
Доступ создают на главном компьютере — у каждого устройства свой.
На всех устройствах выберите одну и ту же папку.
