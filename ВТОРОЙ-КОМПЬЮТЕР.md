# Как подключить второй компьютер

Главный компьютер хранит ваши входы в аккаунты (Claude, Codex, Google) и раздаёт их
вашим устройствам в зашифрованном виде. У каждого устройства свой доступ и личный пароль.
Пароли от самих аккаунтов вводить не нужно.

## Шаг 1. Главный компьютер (один раз)

1. Откройте **Agent Hub** → вкладка **«Настройки»** → раздел **«Устройства и синхронизация»**.
2. Нажмите **«Подключить»** → выберите **«Этот компьютер — главный»** → **«Сделать главным»**.
3. Если Windows спросит про брандмауэр — нажмите **«Разрешить»** (частные сети).
4. В разделе появится **«Адрес для других устройств»**, например `192.168.3.5:47800`. Запишите его.
5. В блоке **«Доступы устройств»** нажмите **«Добавить доступ»**:
   - имя — например `Ноутбук`;
   - личный пароль — не короче 8 символов, дважды.

   Пароль нигде не сохраняется — запомните его. Для каждого следующего устройства создайте отдельный доступ.

## Шаг 2. Установить Agent Hub на второй компьютер

Любой из двух способов:

- **Готовая программа.** На главном компьютере в том же разделе нажмите **«Установщик на рабочий стол»** —
  появится `Agent Hub — установка.zip` (около 160 МБ). Перенесите его на второй компьютер (флешка, облако),
  распакуйте в любую папку, например `C:\AgentHub`, и запустите `AgentHub.exe`.
- **Из GitHub.** Установите [Node.js](https://nodejs.org) и [Git](https://git-scm.com), затем:

  ```
  git clone https://github.com/ivankacioni/agent-hub.git
  cd agent-hub
  npm install
  node build-app.js
  ```

  Появится ярлык **Agent Hub** на рабочем столе.

Также установите на второй компьютер **Node.js** (nodejs.org) — через него Agent Hub ставит программы агентов.

## Шаг 3. Подключить второй компьютер

1. Откройте **Agent Hub** → **«Настройки»** → **«Устройства и синхронизация»** → **«Подключить»**.
2. Выберите **«Подключиться к главному»** и введите:
   - **адрес главного компьютера** — из шага 1, например `192.168.3.5:47800`;
   - **имя доступа** — например `Ноутбук`;
   - **личный пароль доступа**.
3. Нажмите **«Подключить»**. Через несколько секунд появятся ваши агенты, входы в аккаунты и MCP-серверы.
4. Если у агента написано «программа не установлена» — нажмите у него **«Установить»**.

Главный компьютер должен быть **включён, с открытым Agent Hub**, когда второй синхронизируется.
Свежие входы приходят примерно раз в минуту.

## Если второй компьютер не дома

Компьютеры должны «видеть» друг друга. Дома, в одной Wi-Fi-сети, это работает сразу.
Из другого места:

1. Установите [Tailscale](https://tailscale.com/download) на оба компьютера и войдите в один аккаунт Tailscale.
2. На главном компьютере в «Адресах для других устройств» появится адрес `100.x.x.x:47800` с пометкой «Tailscale».
3. На втором компьютере подключитесь по этому адресу.

Открывать порт на роутере не нужно и не стоит.

## Как отключить устройство

На главном компьютере в **«Доступах устройств»** нажмите **«Отозвать»** у нужного доступа:

- устройство выйдет из всех аккаунтов, как только будет в сети;
- ключ хранилища сменится — данные, оставшиеся на том устройстве, станут бесполезны;
- остальные устройства продолжат работать, их пароли менять не нужно.

Если устройство потеряно или украдено и в сеть не выходит — нажмите «выйти на всех устройствах» на сайтах сервисов
(ссылки есть в том же разделе: Google, ChatGPT, Claude), затем войдите заново на главном компьютере.
Новый вход сам разойдётся по остальным устройствам.

## Что защищено

- По сети передаётся только зашифрованное хранилище (AES-256-GCM). Пароли по сети не передаются.
- Главный компьютер отвечает только устройствам с действующим доступом. Любой другой запрос — отказ,
  запись в журнал и уведомление. После 8 неверных попыток адрес блокируется на 30 минут.
- Один доступ работает только на одном устройстве.
- Ключи на диске защищены Windows, токены в интерфейсе показываются звёздочками.

## Частые проблемы

| Сообщение | Что сделать |
|---|---|
| «Главный компьютер недоступен» | Главный включён? Agent Hub на нём открыт? Компьютеры в одной сети или в Tailscale? Разрешён ли Agent Hub в брандмауэре Windows? |
| «Неверное имя доступа или пароль» | Проверьте имя доступа и пароль. Забыли пароль — отзовите доступ на главном и создайте новый. |
| «Этот доступ уже привязан к другому устройству» | Создайте на главном отдельный доступ для этого компьютера. |
| «Временно заблокировал» | Было много неверных попыток. Подождите 30 минут. |
